# Demo Kldero Steak Club

Borrador de demostración (landing de una sola página) para Kldero Steak Club, parrilla uruguaya en Guayaquil (@kldero.ec), con promos, carta, tres locales (Higueras, Monjas y Plaza Guayarte), shows en vivo, reservas y pedidos por WhatsApp. Preparado por IGNIS. Las imágenes son ilustraciones referenciales; irán las fotos originales de Kldero.

**URL:** https://rjaramilloestrada.github.io/demo-kldero/

Es HTML estático (`index.html`, `favicon.svg`, `og.jpg`), sin build ni dependencias salvo Google Fonts.

## Activar GitHub Pages

Settings › Pages › Build and deployment › Deploy from a branch › `main` / `/ (root)` › Save. La URL queda publicada en uno o dos minutos.

## Pendientes por validar con Kldero

- Dos líneas de WhatsApp: 099 798 6596 (pedidos, la que usa el demo) y 099 468 7035 (carta). Confirmar cuál va en cada botón.
- Precios: son provisionales, tomados del menú publicado en Instagram. Falta la carta oficial.
- Nombres dudosos en la carta: "Limonada" y "Porción de morocho".
- Enlace real de PedidosYa (ahora apunta a la página principal de PedidosYa Ecuador).
- Horario de Plaza Guayarte (el demo usa el mismo horario general para los tres locales).
- Costo de envío a domicilio (hoy se dice que se confirma por WhatsApp).
- Canal de reservas y persona de contacto (hoy las solicitudes llegan al WhatsApp de pedidos).
- Fotos originales para reemplazar las ilustraciones.

## Nota para la reunión

El pie de página incluye un simulador de día ("Hoy", "Un martes", "Un sábado") para mostrar el banner de Martes loco y el estado de los locales. Se quita en la versión entregada.
